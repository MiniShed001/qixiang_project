> 版本:1.0 · 更新:2026-10-19
> 技术栈:Django + SQLite + matplotlib + xarray + requests

---

## 1. 项目概述

本系统是一个基于 Django 的气象数据可视化系统,从多个**免费公开、无需 API key** 的
真实数据源抓取六类气象数据,入库后自动生成静态图表(PNG)与动画(GIF),并通过
Web 页面展示。

六大类数据:

| 类别 | 数据源 | 内容 | 周期 |
|------|--------|------|------|
| 地面气象(中国) | Open-Meteo Archive | 气温/露点/湿度/气压/风/降水 | 逐小时,近 7 天 |
| 地面气象(美国) | IEM ASOS | 同上 | 逐小时,近 7 天 |
| 高空气象 | IEM RAOB 探空档案 | 各气压层温度/露点/风 | 每日 2 次 |
| 海洋气象 | NOAA NDBC 浮标 | 波高/波周期/海温/气温/气压/风 | 逐小时,近 45 天 |
| 天气雷达 | IEM 全国雷达拼图 | 基本反射率 n0q | 约 5 分钟一档 |
| 气象卫星 | GOES-16(AWS 开放桶) | ABI 红外云图(netCDF) | 时次图 |
| 风云卫星 | NSMC(需实名注册) | FY-4A/4B AGRI L1 | 管线就绪,待注册 |

所有数据均为真实观测数据,非人工编造。风云卫星因国家卫星气象中心(NSMC)要求
实名注册审核,管线已就绪但默认未启用。

## 4. 数据模型(models.py)

### 4.1 Station —— 站点/浮标元数据(共用)

| 字段 | 类型 | 说明 |
|------|------|------|
| station_id | CharField(20, unique) | 站点编号,如 `CN-北京`、`KOUN`、`41002` |
| name | CharField(100) | 站点名称 |
| latitude / longitude | FloatField | 经纬度 |
| kind | choices | `surface` 地面 / `upperair` 高空 / `ocean` 海洋 |
| source | CharField(80) | 数据来源标识 |

### 4.2 SurfaceObservation —— 地面观测(逐小时)

外键 `station`(related_name=`surface_obs`);字段:time、temperature_c、
dewpoint_c、humidity_pct、wind_dir_deg、wind_speed(m/s)、pressure_hpa、
precip_mm。索引 `(station, time)`。

### 4.3 UpperAirLevel —— 高空探测层(一次探空 = 多条层记录)

外键 `station`(related_name=`upperair_levels`);字段:time、pressure_hpa、
height_m、temperature_c、dewpoint_c、wind_dir_deg、wind_speed_kt。
按气压降序排序(`-pressure_hpa`)。

### 4.4 OceanObservation —— 海洋浮标观测

外键 `station`(related_name=`ocean_obs`);字段:time、wind_dir_deg、
wind_speed_ms、gust_ms、wave_height_m、wave_period_s、wave_dir_deg、
pressure_hpa、air_temp_c、water_temp_c、dewpoint_c。

### 4.5 RadarProduct —— 天气雷达拼图

字段:time、product(默认 `n0q`)、region(默认 `uscomp`)、
image(FileField → `radar/`)、source_url。

### 4.6 SatelliteImage —— 气象卫星云图

字段:satellite(choices:GOES-16/18、Himawari-8、FY-4A/4B)、channel(如 `C13`)、
time、image(FileField → `satellite/`)、source_url、note。

> 所有表 `verbose_name` 均为中文,后台管理自动使用中文界面。

## 5. 数据抓取(fetch.py)

统一入口 `_get(url, params, timeout=90, retries=3)`,带 UA 头、指数退避重试。

### 5.1 地面(中国)—— `fetch_surface_openmeteo(city, lat, lon, days=7)`

调用 Open-Meteo 历史档案 API,逐小时返回。注意:风速单位 km/h → m/s(÷3.6)。

### 5.2 地面(美国)—— `fetch_surface_asos(station, days=7)`

调用 IEM ASOS 接口(`asos.py`),CSV 格式解析。单位换算:
华氏→摄氏、节→m/s(×0.514444)、英寸→mm(×25.4)。

### 5.3 高空—— `fetch_upperair(station, days=7, fallback=(...))`

调用 IEM RAOB 接口(`raob.py`)。站点编号需 **K 前缀**(如 `KOUN`)。
近期无数据时自动回退到 `fallback` 指定的历史日期。

### 5.4 海洋—— `fetch_ocean(buoy_id)`

请求 `https://www.ndbc.noaa.gov/data/realtime2/{buoy_id}.txt`,解析固定列
(`NDBC_FIELDS` 列表)。缺失值 `M`/`MM` 转 None。

### 5.5 雷达—— `fetch_radar_composite(raw_dir, n_steps=8, step_min=30)`

按整 10 分钟时次拼接 URL 下载 IEM 美国全国拼图(n0q PNG),存 `data/raw/`。

### 5.6 卫星(GOES)—— `fetch_goes_cmi(raw_dir, n_steps=5, channels=('C13',))`

通过 S3 桶 `https://noaa-goes16.s3.amazonaws.com` 列出
`ABI-L2-CMIPC/{year}/{doy}/{hour}/` 目录(解析 S3 XML),选取若干小时的
C13 通道 netCDF 文件下载。

### 5.7 卫星(风云)—— `fetch_fy4(account=None)`

返回说明信息,提示需在 NSMC 实名注册后下载 FY-4 HDF5 数据,解析方式见
satpy 的 `agri_l1` reader。当前默认未启用。

## 6. 可视化(plotting.py)

使用 matplotlib Agg 后端(无 GUI),`figure.dpi=110`,`savefig.bbox='tight'`。
**所有图内文字用英文标注**(避免中文字体缺失),网页界面用中文。已注册
Noto Sans CJK 中文字体兜底(站点名可能含中文)。

主要函数:

| 函数 | 产出 |
|------|------|
| plot_surface_ts | 多站点时序曲线 |
| plot_wind_rose | 16 方位风玫瑰(按风速分档堆叠) |
| plot_skewt | 标准 Skew-T log-P 斜温图(等温线/干绝热线/饱和混合比线/风羽) |
| plot_upper_profile | 温度/露点随气压垂直廓线 |
| plot_ocean_scatter | 风速-波高散点 + 线性拟合 |
| plot_station_map | 世界地图(海岸线 GeoJSON + 站点标记) |
| render_goes_ir | GOES netCDF → 灰度 PNG(红外亮温) |
| images_to_gif | 多帧图像合成 GIF |
| ocean_evolution_anim | 波高逐帧演变动画 |

## 7. 管理命令

### 7.1 `ingest_data` —— 抓取并入库

```
../venv/bin/python manage.py ingest_data
```

流程:按 地面(中)→ 地面(美)→ 高空 → 海洋 → 雷达 → GOES → 风云 的顺序
抓取,每种数据先 `delete()` 旧记录再 `bulk_create()` 新记录(全量覆盖式入库)。

### 7.2 `make_visuals` —— 生成图表与动画

```
../venv/bin/python manage.py make_visuals
```

从数据库读取数据,生成静态图到 `meteo/static/meteo/plots/`、GIF 到
`meteo/static/meteo/img/`。产出物由 Web 页面直接引用,不实时生成。

> 两者的先后关系:`ingest_data` 先入库,`make_visuals` 再基于库中数据出图。

## 8. Web 视图与路由(views.py / urls.py)

`app_name = 'meteo'`,根路由在 `mysite/urls.py` 中以 `path('', include('meteo.urls'))`
挂载,故以下路径均为站点根路径:

| 路径 | 视图 | 说明 |
|------|------|------|
| `/` | index | 总览:6 类数据计数 + 站点数 |
| `/surface/` | surface | 地面:温度时序(中/美)+ 站点表 |
| `/upperair/` | upperair | 高空:各站最新探空 + 层数 |
| `/ocean/` | ocean | 海洋:波高时序 + 浮标表 |
| `/radar/` | radar | 雷达:拼图列表 + GIF 动画 |
| `/satellite/` | satellite | 卫星:GOES / 风云云图 |
| `/admin/` | Django admin | 后台管理 |

视图通用辅助函数:`_downsample_hourly`(按小时聚合取均值)、
`_aligned`(多序列共享时间轴对齐)、`_group`(按站点聚合)。

## 12. 扩展指南

### 12.1 新增地面城市

在 `ingest_data.py` 的 `SURFACE_CN` 列表追加 `(城市名, 纬度, 经度)` 即可,
下次 `ingest_data` 自动抓取该城市数据。

### 12.2 启用风云卫星

1. 到 https://satellite.nsmc.org.cn 实名注册并通过审核;
2. 在 `fetch.py` 的 `fetch_fy4(account)` 中实现登录 → 检索 → 下单 → 下载;
3. 用 satpy(`reader='agri_l1'`)解析 HDF5 渲染云图;
4. 在 `ingest_data.py` 中把 `_ingest_fy` 的占位逻辑替换为实际入库。

### 12.3 新增卫星通道

修改 `fetch_goes_cmi` 的 `channels` 参数与 `render_goes_ir` 的 `vmin/vmax`,
并相应调整 `SatelliteImage.channel` 记录。

## 13. 已知问题与注意

1. **GOES CONUS CMIPC 数据只到 2025-04**(AWS 桶现状),`_goes_latest_year_doy`
   会回退扫描 2025/2024/2023,已入库云图可能是历史时次。
2. 探空站编号必须用 K 前缀,否则 IEM RAOB 接口无数据。
3. 抓取依赖外网,离线环境 `ingest_data` 会失败;已入库的数据与图表不受影响。
4. `ingest_data` 为全量覆盖式入库,不会做增量合并。
